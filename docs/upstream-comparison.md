## Recommendation summary

- Add `@piewf/herdr`: the only companion with a functional gap. Upstream dotenv already loads it, this fork already carries its settings key, and it stays inert outside a Herdr pane. The change touches `pi/agent/pi-packages.txt` and `pi/agent/settings.json` and must keep the two in step. It is not done here, because this task is documentation only.
- Do not add `@piewf/cli`: it is not a Pi package and `npx -p @piewf/cli piewf doctor` already works on demand.
- Do not add `@piewf/pi-ext-roles` as a Pi package: core pulls it in. A global `pi-role` is only useful after the roles move to `~/.pi/agent/pi-ext-roles/roles/`.
